- k3s-master: 2 vCPU / 2 GB RAM / 25 GB disk
- k3s-worker1: 2 vCPU / 2 GB RAM / 20 GB disk
- k3s-worker2: 2 vCPU / 2 GB RAM / 20 GB disk

## Networking
- libvirt NAT network: lab-net (192.168.123.0/24)
- Bridge: virbr1
- Static DHCP leases via `libvirt_network.lab` in `terraform/network.tf`
- Forward mode: NAT with port range 1024–65535
- Internal domain: `lab.internal`

## Storage
- Pool: `lab` (dir type) at `/var/lib/libvirt/images/lab`
- Pool permissions: mode `0770`, owner `root`, group `libvirt-qemu` (64055)
- Backing-chain volumes via `backing_store` on `libvirt_volume`
- Base image: `<pool>/base/ubuntu-24.04-server-cloudimg-amd64.img`
- Volume ownership: `libvirt-qemu:libvirt-qemu 640`

## Libvirt Architecture
- Daemon mode: **monolithic** (`libvirtd.service` active, no split `virtqemud`)
- AppArmor: domain-specific profiles auto-generated by `virt-aa-helper`
  - Local override: `/etc/apparmor.d/local/abstractions/libvirt-qemu`
  - Rule: `**/*.{qcow2,img} rwk,`
- Disk source type: `file` (not `volume`) — required for correct AppArmor profile generation

## Provisioning Pipeline
1. Packer — builds golden qcow2 with cloud image + baseline packages (SSH key auth)
2. Terraform — pool, network, volumes (backing-chain), VMs (cloud-init, file-based disks)
3. cloud-init — SSH key auth, hostname, sysctl tuning, package install
4. Ansible — k3s server, k3s agents, jumpbox CLI tooling

## Terraform
- Provider: `dmacvicar/libvirt ~> 0.9`
- Module structure: `modules/compute/` (extracted from root `main.tf`)
- Backend: **local state only** (`terraform.tfstate`). No remote backend.
  - Run `make state-backup` before destructive operations to snapshot state.
- `lifecycle { ignore_changes = [devices] }` works around provider v0.9.x PTY path bug.
- No `prevent_destroy` lifecycle guard — `make tf-destroy` has an interactive prompt instead.
- Destroy guard: `make tf-destroy` prompts for confirmation; `make tf-destroy-auto` also prompts.
- `libvirt_network` manages all DHCP leases — no manual `virsh net-update` needed.

## Ansible
- Dynamic inventory: `ansible/inventories/terraform.py`
  - Groups: `jumpboxes`, `k3s_server`, `k3s_agents`
  - Host IPs match the static DHCP leases from terraform
- Playbook structure:
  - `site.yaml` — orchestrates jumpbox → k3s-server → k3s-agent
  - `jumpbox.yaml` — CLI tools (kubectl, helm, k9s, jq)
  - `k3s-server.yaml` — k3s server install, token extraction, API wait
  - `k3s-agent.yaml` — k3s agent install with server token
- Role: `roles/k3s/` (shared server/agent install pattern)
- Token distribution: server playbook slurps `/var/lib/rancher/k3s/server/node-token` and exposes via `hostvars`

## Security
- SSH key auth only (ed25519, no password auth)
- `lock_passwd: true` and `ssh_pwauth: false` in cloud-init
- `disable_root: true` enforced via cloud-init
- AppArmor confinement per VM domain profile (auto-generated by libvirt)
- No secrets in git (static cloud-init files removed)
- Packer image uses SSH key auth (no password)

## Operations
- Snapshots: `make snapshot` creates atomic snapshots of all running VMs
- State backup: `make state-backup` timestamps `terraform.tfstate`
- Pre-flight checks: `make check` validates dependencies before apply
- End-to-end: `make up` runs check → terraform apply → ansible site

## Rebuild Procedure

```bash
# 1. Install host dependencies
sudo apt install -y qemu-kvm libvirt-daemon-system virtinst terraform packer ansible
sudo usermod -aG libvirt,kvm,libvirt-qemu $USER
# log out and back in for group changes to take effect

# 2. Create pool
virsh pool-define-as lab dir --target /var/lib/libvirt/images/lab
virsh pool-build lab && virsh pool-start lab && virsh pool-autostart lab
chown -R root:libvirt-qemu /var/lib/libvirt/images/lab
chmod 2770 /var/lib/libvirt/images/lab /var/lib/libvirt/images/lab/base
mkdir -p /var/lib/libvirt/images/lab/base

# 3. Install AppArmor rule
echo '  "/var/lib/libvirt/images/lab/**/*.{qcow2,img}" rwk,' \
  | sudo tee /etc/apparmor.d/local/abstractions/libvirt-qemu
sudo systemctl reload apparmor

# 4. Build base image
make packer-build

# 5. Provision everything
make up
```
